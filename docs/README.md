# ByBots documentation

This directory contains the public ByBots documentation. Procedures containing
infrastructure-specific addresses, accounts, backup destinations, or private
paths must stay in a separate private operations repository.

The current evaluation build is `0.3.1-alpha.1`. See the
[changelog](../CHANGELOG.md) for delivered changes and the
[support policy](SUPPORT.md) for release-gated work.
